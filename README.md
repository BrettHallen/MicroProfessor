# Micro Professor MPF
The Multitech (Acer) Micro Professor MPF range of computers:

- MPF-I: Z80 trainer with six 7-digit display
- MPF-IA: Z80 trainer with six 7-digit display
- MPF-IB: Z80 trainer with six 7-digit display
- [MPF-IP: Z80 trainer with 20-digit VFD and QWERTY keyboard](/MPF-IP)
- MPF-I/88: 8088 trainer with 2x20 LCD
- MPF-II: 6502 Apple ][ clone with built-in keyboard
- [MPF-III: 6502 Apple IIe clone with separate keyboard](/MPF-III)
