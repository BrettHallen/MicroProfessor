# PALs (Programmable Array Logic)
Dumps of the PALs from a MOS 1.1 machine courtesy of [RetroAND and Retrolab](https://bitspassats.com).<br>

Interestingly my FDD card (FDI-III) from a later machine has U3 occupied instead of the U7 position on RetroAND's machine.<br>

| PAL # | Use         | Type      | CRC32    | Notes                                        |
|-------|-------------|-----------|----------|----------------------------------------------|
| U3    | Z80 Card    | DM74S274  |          | PB8305040-9C                                 |
| U3    | FDD Card    | DM74S274  |          | FDI-III PB8305050-6B                         |
| U7    | FDD Card    | DM74S274  | C7E54371 | FDI-III PB8305050-6B                         |
| U10   | FDD Card    | DM74S274  | CF528C37 | FDI-III PB8305050-6B                         |
| U29   |             | PAL14L4CN | C09EE203 |                                              |
| U30   |             | PAL14L4CN | 6D914281 |                                              |
| U44   |             | PAL16R8NC |          | Unable to be read                            |
