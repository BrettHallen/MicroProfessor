; ===========================================================================
;  MULTITECH MICRO-PROFESSOR MPF-III  --  KEYBOARD CONTROLLER FIRMWARE
;  Fully annotated disassembly  (independently re-disassembled & verified)
; ===========================================================================
;  CPU      : Intel INS8035N-6  (MCS-48 family, ROM-less, 64 B RAM)
;  EPROM    : 2732 (4 KB), board ref U5,  CRC32 = 46D4227A
;  Verified : 19/Jun/2026  (reassembles byte-exact to ROM 0x800-0xBFF)
;  Source   : original WIP annotation by Brett Hallen, 25/Jan/2026
;
;  EPROM ADDRESS MAPPING
;  ---------------------
;  Only the upper 2 KB of the 2732 is decoded by the keyboard (A11 strapped
;  high). CPU runtime address 0x000 reads EPROM file offset 0x800, so the
;  active 1 KB program at runtime 0x000-0x3FF resides at file 0x800-0xBFF.
;  File 0x000-0x7FF and 0xC00-0xFFF are erased (0xFF).
;  Addresses below are RUNTIME addresses (what the CPU sees).
;
;  MEMORY-MAP HIGHLIGHTS
;    0x000        reset entry (NOP padding -> DIS I -> JMP INIT)
;    0x007        timer/counter interrupt vector -> JMP TIMER_ISR
;    0x009-0x024  INIT: ports, RAM clear, timer start, enter main loop
;    0x026-0x079  SCAN_MATRIX: 11 rows x 8 cols, debounce, dispatch presses
;    0x07A-0x080  DEBOUNCE_RD: 5x sample + AND for stable bits
;    0x081-0x096  PROC_PRESS: walk 8 columns, queue + look up each new press
;    0x097-0x0A9  CLR_FLAGS: reset repeat/timer flags + counters
;    0x0AA-0x0F2  REPEAT_CHK: auto-repeat bookkeeping vs previous code
;    0x0F3-0x102  WAIT_TICK / TIMER_START: timer-flag wait, (re)start timer
;    0x103-0x1FA  TIMER_ISR: ~10 ms tick - repeat timing, strobe, LED blink
;    0x1FB-0x2FC  key-code LOOKUP + modifier adjust (shift/CTRL/ALT/caps)
;    0x300-0x38F  KEYMAP data table (read via MOVP3 A,@A) -- see dump below
;    0x390-0x3F5  CHK_PENDING, MAIN_LOOP, queue + flag helpers
;                 (0x390-0x3FF also doubles as MOVP3 data for some ALT keys)
;    0x3F6-0x3FF  erased filler (0xFF)
;
;  PORT / PIN USAGE
;    BUS    column inputs (active low; complemented in code)
;    P2     row select rows 0-7 (one bit driven low at a time)
;    P1.0-2 row select rows 8-10        P1.3 Caps-lock LED / strobe
;    P1.4   any-key indicator           P1.5/6/7 strobe / CTRL LED / blink
;    T1     SHIFT input (JNT1)   INT     ALT input (JNI)   T0  special remap
;    Key code latched at [0x38]; bit7 of RB1.R7 = strobe/ready.
; ===========================================================================
