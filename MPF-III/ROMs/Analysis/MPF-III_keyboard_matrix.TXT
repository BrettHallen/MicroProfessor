Key points visible in the diagram:
───────────────────────────────────────────────────────────────
• Rows 0–7   → controlled by P2 (one bit low at a time)
• Rows 8–10  → controlled by P1 bits 0,1,2 (when R4 < 4 in scan loop)
• Columns    → read from BUS port (active low → complemented in code)
• Leftmost key in each row = bit 7 of BUS (highest R6 value in that row)
• Rightmost key = bit 0 (lowest R6 in row)
