; Overall Firmware Analysis:
; - MCS-48 (8035) keyboard controller for MPF-III (Apple IIe clone).
; - Initialises ports: BUS/P2 high for inputs, P1 =0xC7 for matrix/LED control.
; - Clears RAM 0x00-0x3F (debounce 0x20-0x3A, queue 0x38-0x3E, counters 0x30-0x36).
; - Timer (~10ms) for debounce/repeat/LED blink.
; - Matrix scan: 11 rows, 8 columns, debounced presses processed to R6 index (0x00-0x57).
; - Lookup in page 3 tables, adjusted for modifiers (shift/CTRL/ALT/caps) to match manual ASCII codes ($00-$06, $1F-$FF).
; - Auto-repeat for $80-$FF except $83 (BREAK), $93 (HALT) at 15/s after 0.9s.
; - Output: Code at system $C000 (low 7 bits), bit7 strobe. Any-key at $C010 bit7.
; - LEDs on P1 (3=caps, 6=CTRL?, 7/5/4 blink/other).
; - Queue/shift for multi-key handling/repeat.
